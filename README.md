# MBU Data Science Learning Portal

A web-based learning portal designed for students to access Data Science learning materials, organize study resources, and practice coding in one place.

## Project Overview

The **MBU Data Science Learning Portal** provides a student-friendly interface for accessing learning resources, uploading PDF materials, and practicing programming. The portal is designed around the student learning experience at Mohan Babu University (MBU).

## Features

- **Student Profile** – Displays student information, including name, roll number, and faculty details.
- **Profile Image** – Allows the student to add or change their profile image.
- **PDF Upload** – Upload and access PDF learning materials through the portal.
- **Persistent PDF Storage** – Uploaded PDFs are stored in browser IndexedDB so they can remain available after refreshing or reopening the browser, until deleted by the user. Clearing browser data may remove locally stored files.
- **Learning Materials** – Provides a dedicated section for managing and accessing uploaded study resources.
- **Code Editor** – Provides a coding environment for writing and practicing programs.
- **Responsive Interface** – Designed to provide a user-friendly learning experience across different screen sizes.
- **MBU-Inspired Branding** – Uses university-themed branding and portal styling.

## Installation and Setup

### 1. Clone or Download the Project

Download the project source code and open its project folder in VS Code.

### 2. Open the Terminal

Navigate to the folder containing `package.json`.

### 3. Install Dependencies

```bash
npm install --legacy-peer-deps
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in the terminal.
